# Rebalance Page — Comprehensive Audit (2026-07-04)

Deep-dive review of everything shipped under the `rebalance_page` initiative
(~21 merged PRs: EOD engine-readout producer, DB table + sync, read endpoints,
16:00 IST scheduler job, rebuilt client `/rebalance` page), across the 4
production portfolios: **om25_v3** (Quality Momentum), **tl25_v3** (Trend
Leaders), **l6_v2** (Core Momentum), **combo_defensive** (Defensive Blend).

Method: three independent read-only audits — **logic correctness**, **UI/UX**,
**operations/bloat** — each tracing the code end-to-end per portfolio. Full
per-lens notes: `audit_logic.md`, `audit_uiux.md`, `audit_ops.md` (scratchpad).
50 relevant unit tests pass locally. Confirmed code bugs (L1, L2) were
re-verified by hand for this document.

---

## Headline

**The core is sound.** The central design bet — *read the engine's own
decision, don't re-implement selection* — holds. All four EOD adapters in
`data_pipeline/eod_proposal.py` were compared line-by-line against their
production runners (`scripts/run_<strategy>_portfolio.py`) and reproduce the
engine call **exactly today** (regime plumbing, `top_n`, `exit_buffer`,
`min_hold_days`, `weekly_rank_check`, drawdown stop, universe, score weights).
The placeholder-bar trick provably changes only the fill price, not membership.
The rebuilt UI has the right hierarchy and the old "No changes file found"
regression is gone. The producer itself is ~1000 LOC of well-factored,
network-free, well-tested code.

**The risks are all peripheral to selection**, in three clusters:
1. **Two confirmed code bugs** — a 2027 holiday-calendar time-bomb (L1) and a
   latent `/summary` crash (L2).
2. **Staleness gaps** — a failed producer can serve a stale/back-dated proposal
   as "upcoming," and nothing structurally guards adapter↔runner drift or
   alerts on a silent producer miss.
3. **Trust/clarity gaps in the client UI** — model-scale ₹ figures shown as if
   they were the subscriber's, no "informational, not advice" caveat, and an
   unexplained bare drawdown number.
Plus one heavy operational redundancy (the EOD job re-runs the entire daily
pipeline) and a Railway-persistence scheme that has become whack-a-mole.

## What is already good (do not regress)

- **UI hierarchy** — the action card leads; SELL/BUY/HOLD are not color-only
  (sign + icon + label); HOLDs collapsed via a semantic button; no-action states
  explained; ₹ personalisation is client-side-only with clear privacy caveats.
- **Producer shape** — `engine_readout.py` / `rebalance_proposal.py` are small,
  pure, fully unit-tested. Per-strategy failure isolation, the signal-day gate
  (idle ~4 of 5 weekdays), idempotent upsert, soft-fail sync, `latest.json`
  pointer reuse — all deliberate and correct. 6 test files, ~1013 LOC, all
  network-free.

# portfolio_risk_2026

Research study, 2026-09-04. **No production code was changed.** Everything
here is analysis plus one candidate configuration awaiting a decision.

Start with **`STATE.md`** to resume. `RESULTS.md` is the full evidence log
(~2,100 lines, chronological, with a contents table at the top).

| file | what it is |
|---|---|
| `STATE.md` | **Read first.** Where the study landed, what is decided, what is open, how to re-run. |
| `PLAN.md` | Why the work started and how the scope grew. |
| `RESULTS.md` | Full chronological evidence log. Every table, every negative result. |
| `TASKS.md` | Item-by-item status, including everything still open. |
| `OM25_V3_CANDIDATE_SPEC.md` | Investor-readable spec of the candidate configuration. |
| `runs/` | Summary CSVs and the equity curves the analysis scripts read. |

Scripts are listed with their purpose and run order in `STATE.md`.

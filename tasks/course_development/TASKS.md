# course_development — phased tasks

This initiative is exploratory. No production implementation begins until the
founder approves the concept and the compliance gate.

## Phase 0 — concept decisions

- [ ] Founder approves or renames “From SIP to Stock Sense.”
- [ ] Confirm four-week/eight-module shape.
- [ ] Confirm target is existing subscribers, acquisition, or a mixed funnel.
- [ ] Choose English-only pilot or English plus one language test.
- [ ] Choose primary AI path: both providers equally, or one main/one appendix.
- [ ] Decide whether the final artifact is a lab report, journal, or both.

## Phase 1 — compliance and data gate

- [ ] Counsel classifies every module and artifact.
- [ ] Review February 2026 RA Master Circular and any later amendments.
- [ ] Confirm disclosures required for AI-assisted research education.
- [ ] Confirm whether portfolio-method comparison is acceptable and in what form.
- [ ] Confirm dataset redistribution rights.
- [ ] Approve synthetic-data fallback.
- [ ] Write prohibited-language and prohibited-feature checklist.

## Phase 2 — two thin prototypes

- [ ] Script and build Module 3 market-weather slice.
- [ ] Create the five-line weather worksheet and rubric.
- [ ] Produce AI lab synthetic dataset and data dictionary.
- [ ] Create starter ZIP and prompts 1-5.
- [ ] Add intentional same-close leakage bug to instructor demo.
- [ ] Observe five learners per slice.
- [ ] Record setup friction, misconceptions, and support burden.

## Phase 3 — pilot authoring

- [ ] Lock learning outcomes and assessment blueprint.
- [ ] Author Modules 0-2 and 4-7.
- [ ] Record short videos/product walkthroughs.
- [ ] Create concept checks with feedback.
- [ ] Create all seven learner artifacts.
- [ ] Red-team claims, links, dates, and examples.
- [ ] Accessibility and mobile review.

## Phase 4 — minimal product surface

- [ ] Define build-time Course/Module manifest for the pilot.
- [ ] Add `/library/courses/<slug>` routes.
- [ ] Reuse Learn and Insights deep-links.
- [ ] Add local progress only.
- [ ] Add privacy-minimal events from `PILOT.md`.
- [ ] Do not add backend, billing, broker, or personal-data storage.
- [ ] Browser-test complete journey on mobile and desktop.

## Phase 5 — run and evaluate

- [ ] Recruit 20-24 learners.
- [ ] Run pre-course baseline.
- [ ] Facilitate four-week cohort.
- [ ] Review weekly pulse data.
- [ ] Conduct exit interviews.
- [ ] Score artifacts blind to engagement data.
- [ ] Compare results with go/no-go gates.
- [ ] Write `RESULTS.md` with shipped, learned, stopped, and next.

## Deferred backlog

- [ ] Cross-device progress via Clerk.
- [ ] Full courses publishing contract in finance-content-os.
- [ ] Certificate tied to artifact quality.
- [ ] Hindi or another regional-language version.
- [ ] Recurring weekly market-weather practice.
- [ ] Advanced out-of-sample/system-builder course.
- [ ] Subscriber community or cohort matching.
